# Workflow — Start Project

## Goal

Initialize every AI session consistently before development begins.

---

# Step 1 — Read Context

Read these files in order:

1. AI_GLOBAL_RULES.md
2. AI_STARTUP_CONTEXT.md
3. AI_MASTER_CONTEXT.md
4. PROJECT_CONTEXT.md
5. AI_OS_INDEX.md

---

# Step 2 — Load Required Skills

Load only the skills required for the current task.

Examples:

Frontend work:

- Frontend Engineer
- UI/UX Designer

Architecture:

- Technical Architect

Performance:

- Performance Engineer

SEO:

- SEO Engineer

Debugging:

- Debugging Engineer

---

# Step 3 — Analyze

Before writing code:

- inspect project structure
- identify affected files
- explain the reason briefly
- avoid unnecessary changes

---

# Step 4 — Execute

Implement only the requested work.

Do not:

- redesign unrelated sections
- change architecture
- add features not requested

---

# Step 5 — Verify

Before finishing:

- verify build
- verify lint
- verify TypeScript
- verify performance impact

---

# Step 6 — Report

Summarize:

- files changed
- reason
- dependencies
- next logical step
