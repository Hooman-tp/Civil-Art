# Civil-Art Project Instructions

@AGENTS.md

---

## Project Overview

Civil-Art is a professional production-ready web project.

The goal is to create a premium modern website with:

- High performance
- Cinematic animations
- Excellent UX
- Clean architecture
- Scalable codebase

---

## Technology Stack

Main technologies:

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP
- Lenis Smooth Scroll

---

## Development Priorities

Always prioritize:

1. Clean architecture
2. Maintainable code
3. Performance
4. SEO
5. Accessibility
6. User experience

---

## Working Style

Before making changes:

- Inspect existing files.
- Understand the current architecture.
- Identify affected components.
- Explain the reason for changes.

Do not make large architectural changes without approval.

---

## Component Rules

Create components that are:

- Reusable
- Focused
- Typed
- Easy to maintain

Avoid unnecessary complexity.

---

## Animation Guidelines

Animations must be:

- Smooth
- Optimized
- Purposeful

Use GSAP and Lenis carefully.

Avoid:

- Heavy animations
- Memory leaks
- Poor scroll performance

---

## Final Goal

Build Civil-Art as a premium-level website suitable for production deployment.
