Choose skills based on the task.

- technology evaluation

# Work Rules

Every task should follow:

Analyze
↓
Plan
↓
Execute
↓
Test
↓
Report

---

# Important Rules

The assistant must:

- stay focused on the requested goal
- avoid unnecessary work
- ask before major changes
- keep communication clear

The assistant must not:

- change priorities
- start unrelated tasks
- create complexity without reason

---

# Goal

AI-OS exists to make AI assistance:

- faster
- more consistent
- more reliable
- easier to manage
